② 출제 의도와 진행 팁

이 시험은 지텔프 독해·어휘 파트의 'In the context of the passage, ○○ means ___' 유형을 따른 연습용 문제입니다. 정답은 문맥에서 결정되고, 오답은 같은 단어의 다른 뜻, 철자가 비슷한 단어, 반의어로 만들었습니다.
· 이 회차는 DAY 05의 지텔프 동의어 빈출 30단어(commit, exceed, raise, determine, recognize, reflect, attribute 등)로 구성했습니다.
· 다의어(raise, commit, recognize, reflect, determine, tough, revolution)는 이번 회차에서 한 가지 뜻으로 먼저 출제했고, 오답에 다른 뜻을 함정으로 넣었습니다.
· 채점 기준 제안: 27개 이상(90%) 우수 / 23~26개 안정 / 22개 이하 → 오답 단어를 해당 DAY 퀴즈 Part 1·4로 복습.
· 지문 속에서 밑줄 단어의 앞뒤 3~4단어(목적어·전치사·접속어)를 먼저 읽는 습관을 만들어 주세요. 소거법보다 '문장 속 뜻 → 보기 대입'이 75점 이상의 열쇠입니다.

③ 문항별 해설

1. respond  정답 (b) react  (보기: complain / react / imagine / wait)
문맥 단서 the staff ... had to respond quickly(직원들은 빠르게 ~해야 했다) → '대응하다'.
오답 함정 wait는 quickly와 충돌하는 반의어 함정.
지도 팁 respond = react(반응하다) / answer·reply(응답하다). response(명). 지텔프: respond = reply.
2. tough  정답 (d) difficult  (보기: strong / pleasant / familiar / difficult)
문맥 단서 a tough situation, because more than two hundred guests were asleep(200명이 자고 있어서) → '어려운'.
오답 함정 strong은 tough의 '강인한' 뜻을 이용한 함정.
지도 팁 tough = hard/harsh(어려운) / strong(강인한).
3. surrounding  정답 (b) nearby  (보기: distant / nearby / famous / empty)
문맥 단서 the surrounding streets(~ 거리들) crowded with fire trucks → '주변의'.
오답 함정 distant는 반의어 함정.
지도 팁 surrounding = neighboring/adjacent(주변의). surround(동), surroundings(명).
4. dependent  정답 (a) reliant  (보기: reliant / independent / careless / curious)
문맥 단서 dependent on their parents for food(먹이를 부모에게 ~) → '의존하는'.
오답 함정 independent는 반의어 함정(철자가 비슷).
지도 팁 dependent = reliant(의존하는) ↔ independent(독립적인). depend(동).
5. committed  정답 (d) dedicated  (보기: borrowed / wasted / refused / dedicated)
문맥 단서 committed two years to studying them(2년을 연구에 ~) → '바쳤다, 헌신했다'.
오답 함정 wasted는 time과 어울리는 함정이지만 긍정적 문맥과 어긋납니다.
지도 팁 commit = 저지르다(do) / 약속하다 / 헌신하다(dedicate). 지텔프: committed = dedicated.
6. exceeded  정답 (b) surpassed  (보기: avoided / surpassed / repeated / delayed)
문맥 단서 the final number of nests exceeded every expectation(둥지 수가 모든 기대를 ~) → '넘어섰다'.
오답 함정 avoided/delayed는 expectation과 어울려 보이는 함정.
지도 팁 exceed = surpass(넘다, 초과하다). 지텔프: exceeded = surpassed.
7. colleague  정답 (d) co-worker  (보기: customer / relative / neighbor / co-worker)
문맥 단서 My ___ Ben is a designer(디자이너인 내 ~ 벤) at the office → '동료'.
오답 함정 customer/neighbor는 사람 명사라 고르기 쉬운 함정.
지도 팁 colleague = co-worker/associate(동료).
8. talented  정답 (d) gifted  (보기: polite / tired / lucky / gifted)
문맥 단서 a ___ designer(~ 디자이너) → '재능 있는'.
오답 함정 lucky는 designer 칭찬으로 어울려 보이는 함정.
지도 팁 talented = gifted(재능 있는). talent(명).
9. revolution  정답 (c) transformation  (보기: rotation / rebellion / transformation / tradition)
문맥 단서 started a revolution in the way people shop(쇼핑 방식의 ~) → '변혁, 혁신'.
오답 함정 rotation/rebellion은 revolution의 다른 뜻(공전·반란)을 이용한 함정.
지도 팁 revolution = 혁명(rebellion) / 변혁(change, transformation) / 공전.
10. complimentary  정답 (a) free  (보기: free / praising / expensive / limited)
문맥 단서 a ___ breakfast each morning(매일 아침 ~ 조식) → '무료의'.
오답 함정 praising(칭찬하는)은 complimentary의 다른 뜻을 이용한 함정.
지도 팁 complimentary = free(무료의) / 칭찬하는. compliment(명)와 complementary(보완하는) 구별.
11. require  정답 (a) need  (보기: need / enjoy / offer / avoid)
문맥 단서 rooms with a sea view require an early booking(바다 전망 방은 일찍 예약을 ~) → '필요로 하다'.
오답 함정 offer는 resort 문맥의 함정.
지도 팁 require = demand/need(필요하다, 요구하다). requirement(명).
12. scarce  정답 (b) rare  (보기: luxurious / rare / cheap / noisy)
문맥 단서 require an early booking, because they are scarce(일찍 예약해야 하는 이유) → '부족한'.
오답 함정 cheap/luxurious는 방 설명으로 어울려 보이는 함정.
지도 팁 scarce = limited/insufficient/rare(부족한). scarcely(부: 거의 ~않다).
13. burst  정답 (d) exploded  (보기: froze / dried / shrank / exploded)
문맥 단서 A water pipe burst under Oak Street(수도관이 ~) → '터졌다'.
오답 함정 froze/dried는 water 문맥의 함정.
지도 팁 burst = explode(터지다). burst into tears(울음을 터뜨리다).
14. raised  정답 (a) mentioned  (보기: mentioned / grew / lifted / built)
문맥 단서 raised the problem with the city office(시청에 문제를 ~) → '제기했다, 언급했다'.
오답 함정 lifted(들어 올렸다)는 raise의 가장 흔한 뜻을 이용한 함정.
지도 팁 raise = 들어 올리다(lift) / 높이다(increase) / 언급하다(mention). 지텔프: raised = mentioned.
15. numerous  정답 (b) many  (보기: certain / many / few / serious)
문맥 단서 sent numerous letters until the road was finally repaired(길이 고쳐질 때까지 ~ 편지) → '수많은'.
오답 함정 few는 반의어 함정.
지도 팁 numerous = many/plentiful(수많은). number(명).
16. determine  정답 (a) identify  (보기: identify / divide / alter / affect)
문맥 단서 determine why the old bridge cracked(다리가 갈라진 이유를 ~) → '알아내다'.
오답 함정 affect(영향을 주다)는 철자·의미 모두 비슷해 보이는 함정.
지도 팁 determine = identify/discover(알아내다) / decide(결정하다). 지텔프: determine = identify.
17. wealthy  정답 (b) rich  (보기: young / rich / kind / famous)
문맥 단서 A ___ businessman has offered to pay for the study(연구비를 대겠다는 ~ 사업가) → '부유한'.
오답 함정 famous/kind는 사람 수식어로 어울려 보이는 함정.
지도 팁 wealthy = rich/affluent/prosperous. wealth(명).
18. artificial  정답 (a) man-made  (보기: man-made / natural / ancient / fresh)
문맥 단서 artificial wind made in a laboratory(실험실에서 만든 ~ 바람) → '인공의'.
오답 함정 natural은 반의어 함정.
지도 팁 artificial = man-made(인공의) ↔ natural. artificial intelligence.
19. broaden  정답 (b) widen  (보기: shorten / widen / repair / test)
문맥 단서 broaden students' views of the world(학생들의 세계관을 ~) → '넓히다'.
오답 함정 shorten은 반의어 함정.
지도 팁 broaden = widen/expand(넓히다). broad(형).
20. engaging  정답 (d) charming  (보기: boring / expensive / local / charming)
문맥 단서 The speakers were engaging, and many students stayed after the talks(강연 뒤에도 남았다) → '매력적인'.
오답 함정 boring은 반의어 함정.
지도 팁 engaging = charming/attractive/appealing(매력적인). engage(동).
21. attribute  정답 (c) credit  (보기: measure / doubt / credit / hide)
문맥 단서 attribute the rise in attendance to the new club(출석률 상승을 새 동아리 ~) → '~의 덕으로 돌리다'.
오답 함정 measure(측정하다)는 rise와 연결되는 함정.
지도 팁 attribute(동) = credit/ascribe(~로 돌리다). attribute(명) = trait(자질). 지텔프: attribute = trait.
22. recognized  정답 (c) acknowledged  (보기: copied / forgotten / acknowledged / identified)
문맥 단서 skill was finally recognized by museums(실력이 마침내 박물관들에 ~) → '인정받았다'.
오답 함정 identified(식별되었다)는 recognize의 다른 뜻을 이용한 함정.
지도 팁 recognize = 알아보다(identify) / 인정하다(accept, acknowledge). 지텔프: recognized = accepted.
23. guarantee  정답 (d) assure  (보기: reduce / cancel / refuse / assure)
문맥 단서 guarantee that every order arrives in two days(주문이 이틀 안에 도착하도록 ~) → '보장하다'.
오답 함정 cancel/refuse는 order와 어울리는 함정.
지도 팁 guarantee = assure/ensure/promise(보장하다). 명사 = 보증(warranty).
24. attach  정답 (a) join  (보기: join / remove / open / copy)
문맥 단서 attach a photo of the broken item to the return form(사진을 양식에 ~) → '첨부하다'.
오답 함정 remove는 반의어 함정.
지도 팁 attach = join/fasten/stick(붙이다, 첨부하다). attachment(명).
25. supervisor  정답 (c) manager  (보기: customer / reporter / manager / neighbor)
문맥 단서 My ___ at the warehouse(창고의 내 ~) is patient and teaches me → '관리자'.
오답 함정 customer는 같은 문단에 등장해서 헷갈리는 함정.
지도 팁 supervisor = manager/inspector(관리자, 감독관). supervise(동), supervision(명).
26. guilty  정답 (c) ashamed  (보기: proud / confused / ashamed / sleepy)
문맥 단서 made a mistake ... felt guilty all day(실수해서 하루 종일 ~) → '죄책감이 드는'.
오답 함정 proud는 반의어 함정.
지도 팁 guilty = 죄책감이 드는(ashamed, sorry) / 유죄의(culpable). guilt(명).
27. forecast  정답 (b) prediction  (보기: history / prediction / record / map)
문맥 단서 the weather forecast before booking trucks(트럭을 예약하기 전 날씨 ~) → '예보'.
오답 함정 record/map은 weather와 연결되는 함정.
지도 팁 forecast(명) = prediction. forecast(동) = predict/anticipate/foresee.
28. arise  정답 (a) occur  (보기: occur / disappear / end / improve)
문맥 단서 If any problems arise during the test(테스트 중 문제가 ~하면) → '발생하다'.
오답 함정 disappear는 반의어 함정.
지도 팁 arise = happen/occur/emerge(발생하다). 자동사라 목적어가 필요 없음.
29. abandon  정답 (c) leave  (보기: visit / protect / leave / rent)
문맥 단서 abandon the old plan because it cost too much(비용이 커서 옛 계획을 ~) → '버리다, 포기하다'.
오답 함정 protect는 반의어 함정.
지도 팁 abandon = 버리다(leave, dump) / 포기하다(give up). abandon the car.
30. reflect  정답 (c) show  (보기: change / forget / show / hide)
문맥 단서 the new results reflect the hard work(새 결과는 노력을 ~) → '반영하다, 나타내다'.
오답 함정 hide는 반의어 함정.
지도 팁 reflect = 비추다(mirror) / 나타내다(reveal, show). 지텔프: reflects = reveals.
