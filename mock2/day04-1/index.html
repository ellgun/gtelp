② 출제 의도와 진행 팁

이 시험은 지텔프 독해·어휘 파트의 'In the context of the passage, ○○ means ___' 유형을 따른 연습용 문제입니다. 정답은 문맥에서 결정되고, 오답은 같은 단어의 다른 뜻, 철자가 비슷한 단어, 반의어로 만들었습니다.
· 이 회차는 DAY 04의 지텔프 동의어 빈출 30단어(encounter, demand, equip, volunteer, taste, ease, supply 등)로 구성했습니다.
· 다의어(taste, volume, status, succeed, ease, supply)는 이번 회차에서 한 가지 뜻으로 먼저 출제했고, 오답에 다른 뜻을 함정으로 넣었습니다.
· 채점 기준 제안: 27개 이상(90%) 우수 / 23~26개 안정 / 22개 이하 → 오답 단어를 해당 DAY 퀴즈 Part 1·4로 복습.
· 지문 속에서 밑줄 단어의 앞뒤 3~4단어(목적어·전치사·접속어)를 먼저 읽는 습관을 만들어 주세요. 소거법보다 '문장 속 뜻 → 보기 대입'이 75점 이상의 열쇠입니다.

③ 문항별 해설

1. encountered  정답 (d) met  (보기: fed / hunted / avoided / met)
문맥 단서 encountered a family of deer near the lake(호숫가에서 사슴 가족을 ~) → '마주치다'.
오답 함정 hunted/fed는 deer와 어울려 보이는 함정.
지도 팁 encounter = meet/face(마주치다). 지텔프: encountered = met.
2. presence  정답 (a) existence  (보기: existence / gift / sound / danger)
문맥 단서 Their presence surprised us(그들의 ~이 우리를 놀라게 했다) → '존재'.
오답 함정 danger는 야생동물 이미지에서 오는 함정.
지도 팁 presence = existence(존재). present(형: 참석한)와 연결.
3. immediately  정답 (b) instantly  (보기: slowly / instantly / rarely / eventually)
문맥 단서 immediately stopped talking(~ 말을 멈췄다) → '즉시'.
오답 함정 slowly/eventually는 반대 방향의 함정.
지도 팁 immediately = instantly/right away. immediate(형).
4. victims  정답 (d) casualties  (보기: visitors / owners / volunteers / casualties)
문맥 단서 After the flood, ___ are staying in shelters(홍수 뒤 대피소의 ~) → '피해자'.
오답 함정 volunteers는 charity 문맥의 함정.
지도 팁 victim = casualty(피해자, 희생자). victim of a flood/crime.
5. donate  정답 (c) give  (보기: waste / hide / give / sell)
문맥 단서 donate bread every morning(매일 아침 빵을 ~) → '기부하다'.
오답 함정 sell은 bakery 문맥의 함정. free of charge가 반대 단서.
지도 팁 donate = contribute/give. donation(명), contribution(명).
6. supply  정답 (a) provide  (보기: provide / clean / count / borrow)
문맥 단서 supply blankets and lamps free of charge(담요와 램프를 무료로 ~) → '제공하다'.
오답 함정 borrow는 반대 방향의 함정.
지도 팁 supply(동) = provide/give/equip. supply(명) = 공급(량).
7. recruit  정답 (c) hire  (보기: thank / train / hire / fire)
문맥 단서 plan to recruit twenty nurses(간호사 20명을 ~) → '채용하다'.
오답 함정 train은 hospital 문맥에서 고르기 쉬운 함정.
지도 팁 recruit(동) = 채용하다(gather/enlist). recruit(명) = 신입. recruitment(명).
8. Prospective  정답 (d) potential  (보기: former / skilled / foreign / potential)
문맥 단서 ___ applicants must follow the procedure(~ 지원자는 절차를 따라야) → '장래의, 예비의'.
오답 함정 former(이전의)는 반의어 성격의 함정.
지도 팁 prospective = potential/possible(장래의). prospect(명: 전망).
9. procedure  정답 (a) process  (보기: process / result / payment / reward)
문맥 단서 first fill in an online form, then attend an interview(순서대로) → '절차'.
오답 함정 payment는 form 때문에 고르는 함정.
지도 팁 procedure = process/step(절차). follow the procedure.
10. taste  정답 (d) flavor  (보기: price / smell / size / flavor)
문맥 단서 the taste reminds them of their grandmothers' cooking(할머니 요리를 떠올리게 하는 ~) → '맛'.
오답 함정 smell(냄새)은 요리와 관련된 함정.
지도 팁 taste = flavor(맛) / liking(취향) / judgment(안목). 지텔프: taste = liking.
11. ingredients  정답 (c) components  (보기: tools / receipts / components / dishes)
문맥 단서 fresh ___ from nearby farms(근처 농장에서 온 신선한 ~) → '재료'.
오답 함정 dishes(요리)는 menu와 연결되는 함정.
지도 팁 ingredient = component/element(재료, 요소).
12. volume  정답 (d) amount  (보기: edition / height / loudness / amount)
문맥 단서 the volume of customers is so high(손님의 ~이 아주 많아) → '양'.
오답 함정 loudness(음량)는 volume의 다른 뜻을 이용한 함정.
지도 팁 volume = 음량(loudness) / 양·용량(amount). a high volume of traffic.
13. audit  정답 (b) inspect  (보기: hide / inspect / print / sell)
문맥 단서 audit the company's accounts(회사 장부를 ~) → '감사하다'.
오답 함정 print는 document 때문에 고르는 함정.
지도 팁 audit = inspect(감사하다). auditor(명: 감사관).
14. relevant  정답 (c) related  (보기: old / expensive / related / secret)
문맥 단서 gather every ___ document(모든 ~ 서류를 모으다) → '관련된'.
오답 함정 old/secret은 document 수식어로 어울려 보이는 함정.
지도 팁 relevant = related/pertinent(관련된). relevance(명).
15. status  정답 (a) condition  (보기: condition / salary / owner / deadline)
문맥 단서 update the status of each project(각 프로젝트의 ~을 갱신) → '상태'.
오답 함정 deadline은 project와 연결되는 함정.
지도 팁 status = 지위(position) / 상태(condition).
16. demand  정답 (b) need  (보기: shortage / need / price / complaint)
문맥 단서 rising ___ for electric buses(전기버스에 대한 늘어나는 ~) → '수요'.
오답 함정 shortage(부족)는 supply의 반대 이미지로 헷갈리는 함정.
지도 팁 demand(명) = need/requirement(수요, 요구). 지텔프: demand = requirement.
17. equip  정답 (d) furnish  (보기: clean / remove / replace / furnish)
문맥 단서 equip each bus with a larger battery(각 버스에 더 큰 배터리를 ~) → '갖추게 하다'.
오답 함정 replace는 battery와 어울리는 함정.
지도 팁 equip = furnish/provide. be equipped with ~. 지텔프: equip = furnish.
18. transported  정답 (a) delivered  (보기: delivered / produced / sold / repaired)
문맥 단서 transported by train to cities across the country(기차로 전국 도시로) → '운송되다'.
오답 함정 produced/sold는 factory 문맥의 함정.
지도 팁 transport = deliver/transfer(운송하다). transportation(명).
19. volunteered  정답 (a) offered  (보기: offered / refused / forced / paid)
문맥 단서 more than forty students ___ to help(40명 넘는 학생이 돕겠다고 ~) → '자원했다'.
오답 함정 forced(강요받았다)는 비자발적이라 반대 의미의 함정.
지도 팁 volunteer = offer(자원하다, 제안하다). voluntary(형). 지텔프: volunteered = offered.
20. ease  정답 (b) lessen  (보기: increase / lessen / ignore / measure)
문맥 단서 ease her workload during the busy week(바쁜 주의 업무량을 ~) → '덜어주다'.
오답 함정 increase는 반의어 함정.
지도 팁 ease(동) = relieve/alleviate/lessen/calm(덜다, 안정시키다). ease(명) = 쉬움.
21. progress  정답 (a) advance  (보기: advance / mistake / delay / report)
문맥 단서 proud of the ___ the students made(학생들이 이룬 ~이 자랑스러운) → '발전'.
오답 함정 delay는 반의어 함정.
지도 팁 progress(명) = advance(발전). make progress. progress(동) = proceed.
22. closely  정답 (b) carefully  (보기: loudly / carefully / rarely / quickly)
문맥 단서 watched the animals ___ for six months(6개월간 동물을 ~ 관찰) → '면밀하게'.
오답 함정 quickly는 watched와 어울려 보이는 함정.
지도 팁 closely = carefully(면밀하게) / 밀접하게. close(형).
23. slightly  정답 (b) a little  (보기: finally / a little / suddenly / greatly)
문맥 단서 rose only slightly, so they did not think it affected(조금만 올라서) → '약간'.
오답 함정 greatly는 only와 충돌하는 반의어 함정.
지도 팁 slightly = marginally/a little(약간). slight(형).
24. attempt  정답 (c) try  (보기: rule / report / try / gift)
문맥 단서 first attempt to repeat the study failed(연구를 재현하려는 첫 ~) → '시도'.
오답 함정 report는 study와 연결되는 함정.
지도 팁 attempt = try/effort(시도). attempt to ~(~하려 시도하다).
25. substantial  정답 (c) considerable  (보기: unfair / tiny / considerable / late)
문맥 단서 earned ___ profits this year(올해 ~ 이익) → '상당한'.
오답 함정 tiny는 반의어 함정.
지도 팁 substantial = considerable/large/significant. substantially(부).
26. primary  정답 (b) main  (보기: extra / main / final / private)
문맥 단서 Its ___ goal(회사의 ~ 목표) → '주된'.
오답 함정 final(마지막)은 goal 수식으로 어울려 보이는 함정.
지도 팁 primary = main/chief/leading. primarily(부: 주로).
27. succeed  정답 (b) thrive  (보기: fail / thrive / follow / apologize)
문맥 단서 succeed in the Asian market(아시아 시장에서 ~) → '성공하다'.
오답 함정 follow(뒤를 잇다)는 succeed의 다른 뜻을 이용한 함정.
지도 팁 succeed = thrive(성공하다) / replace·follow(계승하다). success(명).
28. proper  정답 (d) appropriate  (보기: expensive / private / quick / appropriate)
문맥 단서 proper care, including food, exercise, and a clean bed(음식·운동·침대를 포함한 ~ 보살핌) → '적절한'.
오답 함정 expensive/quick은 care를 꾸미는 함정.
지도 팁 proper = appropriate/right/correct(적절한). properly(부).
29. welfare  정답 (c) wellbeing  (보기: wealth / fear / wellbeing / speed)
문맥 단서 work hard for the welfare of the animals(동물의 ~을 위해) → '복지'.
오답 함정 wealth(부)는 철자가 비슷한 함정.
지도 팁 welfare = wellbeing(복지). social welfare.
30. classify  정답 (a) categorize  (보기: categorize / wash / feed / count)
문맥 단서 classify each dog by size and age(크기와 나이로 ~) → '분류하다'.
오답 함정 feed/wash는 shelter 일과 때문에 고르는 함정.
지도 팁 classify = categorize/sort(분류하다). classification(명).
