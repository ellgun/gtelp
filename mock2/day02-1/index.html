② 출제 의도와 진행 팁

이 시험은 지텔프 독해·어휘 파트의 'In the context of the passage, ○○ means ___' 유형을 그대로 옮긴 것입니다. 정답은 문맥에서 결정되고, 오답은 같은 단어의 다른 뜻, 철자가 비슷한 단어, 반의어로 만들었습니다.
· 다의어(run, credit, face, hold, draw, cover, capacity, estate 등)를 일부러 많이 넣었습니다. 75점 이상을 노리는 학생은 '단어 뜻 한 개'가 아니라 '문장 속 뜻'을 고르는 연습이 필요합니다.
· 채점 기준 제안: 27개 이상(90%) 우수 / 23~26개 안정 / 22개 이하 → 오답 단어를 DAY 02 퀴즈 Part 1·4로 복습.
· 학생이 많이 틀리는 순서: 다의어 문항(1, 2, 3, 9, 12, 20, 28~30), 철자 함정 문항(5, 26, 27).

③ 문항별 해설

1. established  정답 (b) founded  (보기: proved / founded / discovered / delivered)
문맥 단서 a small bakery(작은 빵집)를 목적어로 받음 → '빵집을 세웠다(설립했다)'.
오답 함정 proved는 establish의 다른 뜻(입증하다)이라 'that절·사실'을 목적어로 받을 때의 뜻입니다. 목적어가 가게·조직이면 설립.
지도 팁 establish = found(설립) / demonstrate(입증) 두 뜻을 세트로. 목적어가 장소·조직이면 설립, that절이면 입증. 지텔프에서는 두 뜻 모두 출제됩니다.
2. run  정답 (b) manage  (보기: flow / manage / escape / rush)
문맥 단서 run three shops with a staff of twenty(직원 20명으로 가게 세 곳을) → '운영하다'.
오답 함정 rush·flow·escape는 run의 '달리다·흐르다' 계열 뜻을 노린 함정. 목적어가 shops(사업체)임을 보게 하세요.
지도 팁 run = 운영하다(manage)는 지텔프 고빈출. run an enterprise / run a café를 같이 판서하고, 목적어가 사업체면 manage로 치환해 보게 하세요.
3. credit  정답 (d) recognize  (보기: lend / charge / believe / recognize)
문맥 단서 credit her with reviving the neighborhood(동네를 되살린 공을 그녀에게) → '공로를 인정하다'.
오답 함정 believe(믿다), lend(빌려주다), charge(청구하다)는 credit의 다른 의미(신용·대출)를 노린 함정. 'credit A with B' 구조가 단서입니다.
지도 팁 credit A with B = B의 공을 A에게 돌리다. 같은 틀: be credited with ~. 동의어 묶음: recognize, praise, honor.
4. define  정답 (b) determine  (보기: deliver / determine / divide / deny)
문맥 단서 define the limits of safe working hours(안전한 근무시간의 한도를) → '정하다·규정하다'.
오답 함정 'd-' 로 시작하는 동사 3개로 철자 함정을 만든 문항입니다. 소거법이 아니라 'limits와 호응하는 동사'를 찾게 하세요.
지도 팁 define = determine(정하다). 명사형 definition도 함께. define/determine/establish를 '정하다' 묶음으로 외우게 하세요.
5. assess  정답 (d) evaluate  (보기: announce / arrange / assist / evaluate)
문맥 단서 assess a worker's condition(근로자의 상태를) + doctors ask(질문) → '평가하다'.
오답 함정 assist·announce·arrange는 'a-' 철자 함정. assess/access 혼동도 자주 나옵니다.
지도 팁 assess=평가하다(assessment), access=접근하다. 철자 혼동 쌍으로 판서. 동의어: evaluate, rate, estimate.
6. identify  정답 (a) discover  (보기: discover / invent / justify / imagine)
문맥 단서 identify the main cause of the stress(스트레스의 주된 원인을) → '알아내다'.
오답 함정 invent(발명하다)·imagine(상상하다)은 '원인'과 호응하지 않음. identify = 확인하다·식별하다·알아내다 중 문맥에 맞는 뜻 선택.
지도 팁 identify: ① 식별하다(recognize) ② 밝혀내다(discover/determine). 'identify the cause'는 ②. 지텔프는 문맥으로 둘을 구분하게 합니다.
7. approach  정답 (b) method  (보기: distance / method / entrance / request)
문맥 단서 a different approach from older ones(기존 방식과 다른) → '접근법·방식'.
오답 함정 entrance·distance는 approach의 '접근(다가감)' 뜻에서 파생된 오해를 노린 함정. 'different ___ from older ones'는 방식을 비교하는 틀.
지도 팁 approach(명) = 방법(way/means), (동) = 다가가다(near). 품사별 뜻을 구분하게 하고 approach to ~ 연어를 같이 외우게 하세요.
8. estimate  정답 (a) guess  (보기: guess / arrange / invest / demand)
문맥 단서 riders will rise by 15 percent(15% 늘 것이다) + planners → '어림잡다·추산하다'.
오답 함정 demand(요구하다)·invest(투자하다)는 뒤 that절(예측 내용)과 호응하지 않음.
지도 팁 estimate는 명사 [-mət]/동사 [-meit] 발음이 다름. 동의어: guess, assess, calculate roughly.
9. capacity  정답 (b) room  (보기: price / room / ability / role)
문맥 단서 each bus ... increased from 60 to 80 passengers(승객 60→80명) → '수용 능력·용량'.
오답 함정 ability·role은 capacity의 다른 뜻(능력·역할)을 노린 함정입니다. 숫자 증가(60→80)가 용량임을 보여 주는 단서.
지도 팁 capacity = ① 능력(ability) ② 수용량(room) ③ 지위·역할(role). 3가지 뜻을 한 줄로 판서하고 문맥으로 고르게 하세요.
10. divided  정답 (a) split  (보기: split / shared / mixed / limited)
문맥 단서 half support, while the other half oppose(절반은 찬성, 절반은 반대) → '갈라진·나뉘어진'.
오답 함정 shared(공유된)는 divide의 '나누다' 뜻만 보고 고르는 함정. 의견이 '갈라졌다'는 뜻이 핵심입니다.
지도 팁 divided = split. 지텔프 어휘 파트에서 divided/segmented/separated 묶음이 출제됩니다. 한국어 '나뉘다'의 두 뜻(분배/분열)을 구분시키세요.
11. deny  정답 (d) reject  (보기: accept / share / report / reject)
문맥 단서 deny any responsibility(책임을 부인한다) → '부인하다·거부하다'.
오답 함정 accept는 정반대 뜻(반의어 함정). but 앞뒤가 '인정하지 않음'이라는 흐름임을 짚어 주세요.
지도 팁 deny = 부인하다/거부하다(reject). 명사 denial. 반의어 admit/accept과 같이 판서해 반의어 함정을 예방하세요.
12. face  정답 (c) confront  (보기: create / avoid / confront / borrow)
문맥 단서 will face serious challenges(심각한 도전에 직면할 것) → '직면하다'.
오답 함정 avoid(피하다)는 반대 뜻. face는 명사(얼굴)로만 아는 학생이 동사 뜻을 놓치는 문항입니다.
지도 팁 face = ① 얼굴 ② 직면하다(confront) ③ 외관 ④ 받아들이다. face challenges/problems는 confront/encounter로 치환.
13. essential  정답 (c) vital  (보기: minor / harmful / vital / rare)
문맥 단서 because they use it to make food(음식을 만들기 때문에) → '꼭 필요한'.
오답 함정 minor(사소한)는 반대 뜻. 이유절이 '필수성'을 설명하는 흐름을 보게 하세요.
지도 팁 essential 동의어 묶음: vital, crucial, critical, key, integral. 한 문장씩 바꿔 읽는 연습을 시키세요.
14. generate  정답 (c) create  (보기: save / transfer / create / measure)
문맥 단서 generate electricity(전기를 만들어 내다) → '창출하다·발생시키다'.
오답 함정 transfer(옮기다)는 electricity와 어울려 보여 함정이 됩니다. 문장 전체(in a similar way)로 '만들다'임을 확인.
지도 팁 generate = create/produce. 명사 generation(세대·발생)과 연결. generate revenue/electricity/interest 연어.
15. demonstrated  정답 (d) proved  (보기: protested / hid / copied / proved)
문맥 단서 demonstrated that a thin solar film can ~(~할 수 있음을) → '입증했다'.
오답 함정 protested는 demonstrate의 '시위하다' 뜻(demonstration=시위)을 이용한 함정. that절을 받으면 입증.
지도 팁 demonstrate = prove/show. that절이면 입증, 사람 주어+행진이면 시위. 지텔프는 '입증'이 훨씬 자주 나옵니다.
16. emphasis  정답 (a) importance  (보기: importance / rule / cost / doubt)
문맥 단서 placed new emphasis on quiet study time(조용한 학습시간에 새로 ~를 두었다) → '중점·강조'.
오답 함정 rule(규칙)은 학교 공지문 분위기 때문에 고르기 쉬운 함정. 'place emphasis on ~' 연어를 알면 바로 풀립니다.
지도 팁 place emphasis on ~ = ~에 중점을 두다. 동사 emphasize, 동의어 stress/importance. 'stress'는 압박이라는 다른 뜻도 있어 함께 판서.
17. focus  정답 (d) center  (보기: divide / reduce / delay / center)
문맥 단서 focus its next budget on soundproofing(다음 예산을 방음에 ~) → '집중하다'.
오답 함정 divide(나누다)는 반대 방향의 함정. focus A on B = A를 B에 집중시키다.
지도 팁 focus = center/concentrate. focus on ~ 형태로 외우게 하고, 명사 focus(초점·집중)도 연결.
18. concentrate  정답 (c) pay attention  (보기: combine / gather / pay attention / relax)
문맥 단서 finally concentrate on their homework(숙제에 ~할 수 있다) → '집중하다'.
오답 함정 gather(모으다)는 concentrate의 '밀집시키다' 뜻을 노린 함정입니다.
지도 팁 concentrate = 집중하다(focus). concentrate on ~. 명사 concentration(집중)도 같이.
19. publicize  정답 (a) promote  (보기: promote / permit / protect / bury)
문맥 단서 grand reopening through posters and social media(포스터·SNS로 재개관을) → '알리다·홍보하다'.
오답 함정 protect/permit은 'p-' 철자 함정. 포스터·SNS가 홍보 수단임을 짚어 주세요.
지도 팁 publicize = promote/advertise. 명사 publicity(홍보·언론의 관심)와 연결. 지텔프 단골 패러프레이징.
20. appearance  정답 (b) look  (보기: debut / look / height / price)
문맥 단서 change in the building's appearance, walls replaced with glass(벽을 유리로 교체) → '외관'.
오답 함정 debut(출연·등장)은 appearance의 다른 뜻을 노린 함정. 건물이 주어이므로 '출연'은 불가.
지도 팁 appearance = ① 외모·외관(look) ② 출연·등장(debut). 문맥(건물/사람 vs 방송/무대)으로 구분.
21. component  정답 (c) part  (보기: price / plan / part / rule)
문맥 단서 each component of the new design, from the roof to the floor(지붕부터 바닥까지) → '구성 요소'.
오답 함정 plan(계획)은 design과 함께 쓰여 고르기 쉬운 함정입니다. from A to B가 '부분들'을 가리킵니다.
지도 팁 component = part/piece(부품·요소). replace old components 연어. 동의어 element도 같이.
22. estate  정답 (d) property  (보기: tax / status / debt / property)
문맥 단서 including a large house and several paintings(큰 집과 그림들을 포함한) → '재산'.
오답 함정 status/debt/tax는 'st-/de-' 철자와 법률 분위기를 이용한 함정. 'house, paintings'가 재산임을 확인.
지도 팁 estate = 재산·사유지(property). real estate(부동산) 연어. 동의어: asset, fortune.
23. conclusion  정답 (d) decision  (보기: summary / argument / ending / decision)
문맥 단서 reached the conclusion that the will was valid(유언장이 유효하다는 ~에 이르렀다) → '결론·판단'.
오답 함정 ending(결말)은 conclusion의 다른 뜻(소설의 결말)을 노린 함정입니다. reach a conclusion이면 '결론을 내리다'.
지도 팁 reach a conclusion = come to a decision. conclusion=①결론·결정 ②마지막 단계. 동사 conclude와 연결.
24. confirm  정답 (b) verify  (보기: cancel / verify / delay / change)
문맥 단서 a letter from the court will confirm the decision(법원 서한이 결정을 ~할 것) → '확인해 주다'.
오답 함정 change/cancel은 decision과 어울려 보이지만 '서한이 결정을 바꾼다'는 흐름이 아닙니다.
지도 팁 confirm = verify/affirm. 명사 confirmation(확인). confirm a reservation(예약 확인) 연어.
25. domestic  정답 (c) internal  (보기: personal / frequent / internal / foreign)
문맥 단서 flights from Seoul(서울발), rarely need foreign currency(외화가 거의 필요 없다) → '국내의'.
오답 함정 foreign은 반대 뜻(반의어 함정). 뒤의 'foreign currency'가 반대 개념으로 단서를 줍니다.
지도 팁 domestic = ① 국내의 ② 가정의(household). domestic flight(국내선), domestic appliance(가정용품).
26. currency  정답 (b) money  (보기: value / money / trend / speed)
문맥 단서 foreign currency(외국 ~) → '통화·화폐'.
오답 함정 trend/speed는 'curr-'와 current(현재의)를 혼동한 함정. currency vs current 철자 구분 포인트.
지도 팁 currency = 통화. current(현재의)와 철자 혼동 주의. foreign currency/exchange 연어.
27. contemporary  정답 (a) modern  (보기: modern / ancient / temporary / similar)
문맥 단서 mix of centuries-old temples and contemporary hotels(수백 년 된 사원과 ~ 호텔) → '현대의'.
오답 함정 temporary(임시의)는 철자가 비슷한 함정, ancient는 반의어 함정. 'centuries-old'와 대비되는 단어가 정답.
지도 팁 contemporary = 현대의·동시대의(modern). temporary와 철자 혼동 주의. 대비 표현(old vs ___)을 단서로 찾게 하세요.
28. hold  정답 (a) conduct  (보기: conduct / grab / contain / keep)
문맥 단서 hold its opening ceremony(개막식을) → '개최하다'.
오답 함정 grab(잡다)·contain(담다)은 hold의 다른 뜻을 이용한 함정. 목적어가 ceremony(행사)이면 개최.
지도 팁 hold = ① 잡다 ② 유지하다 ③ 수용하다 ④ 개최하다(conduct/run) ⑤ 보유하다. 목적어로 뜻을 판별하는 연습.
29. draw  정답 (a) attract  (보기: attract / sketch / tie / remove)
문맥 단서 draw a huge crowd(많은 관중을) → '끌어모으다'.
오답 함정 sketch(그리다)는 painting show와 연결되는 매력적인 함정입니다. 목적어가 crowd(사람들)임을 짚어 주세요. tie(무승부)도 draw의 다른 뜻.
지도 팁 draw = ① 그리다 ② (관심을) 끌다(attract) ③ 추첨 ④ 무승부. 목적어가 사람·관심이면 attract.
30. cover  정답 (c) pay  (보기: hide / protect / pay / discuss)
문맥 단서 ticket sales will cover the costs(티켓 수입이 비용을 ~) → '비용을 치르다'.
오답 함정 hide/protect는 cover의 기본 뜻(덮다)을 이용한 함정. costs(비용)가 목적어이므로 '지불하다'.
지도 팁 cover = ① 덮다(hide) ② 다루다(discuss) ③ 비용을 치르다(pay). cover expenses = pay expenses.
