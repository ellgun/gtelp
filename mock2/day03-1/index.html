A city official added that the money collected will be used to plant trees along the river and to clean the parks nearby.

② 출제 의도와 진행 팁

이 시험은 지텔프 독해·어휘 파트의 'In the context of the passage, ○○ means ___' 유형을 따른 연습용 문제입니다. 정답은 문맥에서 결정되고, 오답은 같은 단어의 다른 뜻, 철자가 비슷한 단어, 반의어로 만들었습니다.
· 이 회차는 DAY 03의 지텔프 동의어 빈출 30단어(impose, impact, settle, favor, edge, assign, decline, limit, phase, release 등)로 구성했습니다.
· 다의어(settle, decline, limit, edge, release, air, assign)는 이번 회차에서 한 가지 뜻으로 먼저 출제했고, 오답에 다른 뜻을 함정으로 넣었습니다.
· 채점 기준 제안: 27개 이상(90%) 우수 / 23~26개 안정 / 22개 이하 → 오답 단어를 해당 DAY 퀴즈 Part 1·4로 복습.
· 지문 속에서 밑줄 단어의 앞뒤 3~4단어(목적어·전치사·접속어)를 먼저 읽는 습관을 만들어 주세요. 소거법보다 '문장 속 뜻 → 보기 대입'이 75점 이상의 열쇠입니다.

③ 문항별 해설

1. impose  정답 (a) levy  (보기: levy / forgive / advertise / remove)
문맥 단서 impose a small fee on plastic bags(비닐봉지에 수수료를) → '부과하다'.
오답 함정 remove/forgive는 fee와 어울려 보이는 반대 방향의 함정.
지도 팁 impose = (의무·세금을) 부과하다. impose a tax/fine/rule 연어.
2. impact  정답 (d) influence  (보기: collision / delay / price / influence)
문맥 단서 strong impact on shopping habits(쇼핑 습관에 미치는) → '영향'.
오답 함정 collision(충돌)은 impact의 다른 뜻을 이용한 함정. 문맥은 규칙의 영향.
지도 팁 impact = effect/influence(영향). 지텔프 동의어 빈출. impact on ~(~에 미치는 영향).
3. largely  정답 (b) mostly  (보기: partly / mostly / hardly / slowly)
문맥 단서 largely aimed at reducing the waste(주로 쓰레기를 줄이려는) → '대부분, 주로'.
오답 함정 partly(부분적으로)는 정도가 약해 mostly와 반대 방향의 함정.
지도 팁 largely = mostly/mainly. large(형)와 구별. largely responsible(주로 책임이 있는).
4. technical  정답 (d) specialized  (보기: friendly / creative / temporary / specialized)
문맥 단서 explain complicated tools(복잡한 도구를 설명) → '전문적인'.
오답 함정 creative(창의적인)는 writer와 어울려 보이는 함정. technical writer = 전문 기술 문서 작성자.
지도 팁 technical = specialized(전문적인). technique(기술)와 연결. technical support.
5. assigned  정답 (b) appointed  (보기: taught / appointed / sold / fired)
문맥 단서 be assigned to a group of five engineers(다섯 명의 엔지니어 팀에) → '배정되다, 임명되다'.
오답 함정 taught(가르쳐지다)는 engineers/explain 때문에 고르는 함정.
지도 팁 assign = 맡기다·할당하다 / 임명하다(appoint). 지텔프: assigned = appointed.
6. wage  정답 (b) pay  (보기: gift / pay / tax / price)
문맥 단서 The job offers a good wage(좋은 ~을 제공) → '임금'.
오답 함정 price(가격)는 돈과 관련된 함정. 일자리가 주는 것은 임금.
지도 팁 wage = pay/payment/salary. minimum wage(최저 임금).
7. vary  정답 (c) differ  (보기: finish / agree / differ / improve)
문맥 단서 vary from person to person(사람마다) → '다르다'.
오답 함정 agree(일치하다)는 반의어 함정.
지도 팁 vary = differ(다르다) / change(다르게 하다). various(형)·variety(명)와 연결.
8. fundamental  정답 (b) basic  (보기: difficult / basic / private / strange)
문맥 단서 A ___ rule for better sleep(수면을 위한 ~ 규칙) → '기본적인'.
오답 함정 difficult(어려운)는 rule의 성격을 잘못 추측한 함정.
지도 팁 fundamental = essential/basic/primary. fundamental change(근본적 변화).
9. damage  정답 (a) harm  (보기: harm / measure / repeat / extend)
문맥 단서 damage the quality of rest(휴식의 질을 ~) → '해치다'.
오답 함정 extend(늘리다)는 quality와 어울려 보이는 함정. 앞 문장 Too much가 부정적 단서.
지도 팁 damage = harm/injure(해를 끼치다). 명사 damage = 손상·피해.
10. origin  정답 (d) beginning  (보기: price / owner / size / beginning)
문맥 단서 the ___ of paper(종이의 ~)을 다룬 전시 → '기원'.
오답 함정 owner/price는 전시품과 관련되어 보이는 함정.
지도 팁 origin = beginning/source(기원). original(형: 원래의)과 구별.
11. sequence  정답 (b) order  (보기: reason / order / copy / pile)
문맥 단서 sequence of steps(단계들의 ~) → '순서'.
오답 함정 pile(더미)은 sheets와 연결되는 함정. steps가 단서.
지도 팁 sequence = order(순서) / series(연속). in sequence(순서대로).
12. relatively  정답 (b) fairly  (보기: hardly / fairly / exactly / never)
문맥 단서 relatively small, so only fifty people(비교적 작아서) → '비교적'.
오답 함정 hardly(거의 ~않다)는 small과 헷갈리는 함정.
지도 팁 relatively = comparatively/somewhat. relative(형: 상대적인).
13. permanent  정답 (c) lasting  (보기: old / narrow / lasting / dangerous)
문맥 단서 replace the wooden one(나무 다리를 대체) → '영구적인'.
오답 함정 old/narrow는 다리를 묘사하는 일반 형용사 함정.
지도 팁 permanent = lasting/persistent. a permanent job(상근직) 연어.
14. phases  정답 (b) stages  (보기: costs / stages / shapes / owners)
문맥 단서 three phases ... each phase will take two months(세 ~, 각 ~은 두 달) → '단계'.
오답 함정 shapes(모양)는 phase의 달 모양 이미지에서 오는 함정. 공사의 단계.
지도 팁 phase = stage(단계). 지텔프: phases = stages.
15. limited  정답 (d) restricted  (보기: extended / doubled / announced / restricted)
문맥 단서 traffic ... limited to one lane(한 차선으로) → '제한되다'.
오답 함정 extended(확대되다)는 반의어 함정.
지도 팁 limit = restrict/confine(제한하다). 지텔프: limited = confined.
16. favors  정답 (c) prefers  (보기: ignores / avoids / prefers / fears)
문맥 단서 favors a fast style(빠른 스타일을 ~) + trained hard → '선호하다'.
오답 함정 avoids/ignores는 반의어 함정.
지도 팁 favor(동) = prefer. favor(명) = 호의. 지텔프: favors = prefers.
17. edge  정답 (a) advantage  (보기: advantage / goal / border / penalty)
문맥 단서 their speed gave them a small edge over the champions(속도가 ~을 줬다) → '우위'.
오답 함정 border(가장자리)는 edge의 다른 뜻을 이용한 함정.
지도 팁 edge = advantage(우위) / border(가장자리). 지텔프: edge = advantage.
18. obvious  정답 (c) clear  (보기: secret / hidden / clear / unlikely)
문맥 단서 it is ___ that the team must improve its defense → '분명한'.
오답 함정 hidden/secret은 반의어 함정.
지도 팁 obvious = clear/apparent/evident. obviously(부).
19. decline  정답 (c) decrease  (보기: return / spread / decrease / refuse)
문맥 단서 the number of wild bees has begun to ___ (벌의 수가 ~하기 시작) → '감소하다'.
오답 함정 refuse(거절하다)는 decline의 다른 뜻을 이용한 함정. 주어가 '수'입니다.
지도 팁 decline = fall/decrease(하락하다) / refuse(거절하다). 지텔프: declined = worsened.
20. limit  정답 (a) restrict  (보기: restrict / test / increase / hide)
문맥 단서 limit the use of these chemicals(화학물질 사용을 ~) → '제한하다'.
오답 함정 increase는 반의어 함정.
지도 팁 limit = restrict/confine/curb. limited(형)·limitation(명).
21. practical  정답 (d) realistic  (보기: unusual / careful / fashionable / realistic)
문맥 단서 costs little and requires no new machines(비용이 적고 새 기계가 필요 없다) → '현실적인'.
오답 함정 careful은 plan 설명에 어울려 보이는 함정.
지도 팁 practical = realistic/actual(현실적인). practicality(실용성).
22. release  정답 (a) launch  (보기: launch / borrow / delete / repair)
문맥 단서 release its new mobile app on Monday(새 앱을 월요일에 ~) → '출시하다'.
오답 함정 borrow는 library 문맥의 함정.
지도 팁 release = 풀어주다(free) / 공개하다(publish) / 발매·출시하다(launch).
23. an array of  정답 (d) a range of  (보기: a lack of / a fear of / a copy of / a range of)
문맥 단서 borrow from an array of e-books(여러 전자책 중에서) → '다양한'.
오답 함정 a lack of(부족)는 반의어 함정.
지도 팁 an array of = a range of/various(다양한).
24. regarding  정답 (a) concerning  (보기: concerning / requiring / avoiding / following)
문맥 단서 Questions regarding the app(앱에 ~ 질문) → '~에 관한'.
오답 함정 following(~ 다음의)은 전치사로 보이는 함정.
지도 팁 regarding = concerning/about/as to(~에 관한).
25. authorized  정답 (c) approved  (보기: invented / refused / approved / delayed)
문맥 단서 has authorized extra payments(추가 수당을 ~) → '허가하다'.
오답 함정 refused(거부했다)는 반의어 함정.
지도 팁 authorize = allow/permit/approve. authorization(명: 허가).
26. occasional  정답 (c) infrequent  (보기: permanent / loud / infrequent / constant)
문맥 단서 the server is down at times(가끔 서버가 다운) → '가끔씩의'.
오답 함정 constant는 반의어 함정.
지도 팁 occasional = casual/intermittent(가끔씩의). occasionally(부).
27. settle  정답 (d) resolve  (보기: pay / move / start / resolve)
문맥 단서 settle their disagreement(의견 충돌을 ~) → '해결하다'.
오답 함정 pay(청산하다)는 settle의 다른 뜻을 이용한 함정. budget이 돈 이야기여서 더 혼동.
지도 팁 settle = solve/resolve(해결하다) / pay(청산하다) / 정착하다. 지텔프: settle = solve.
28. air  정답 (a) broadcast  (보기: broadcast / clean / cool / breathe)
문맥 단서 air a special program(특별 프로그램을 ~) on a radio station → '방송하다'.
오답 함정 breathe(숨 쉬다)는 air(공기)에서 오는 함정.
지도 팁 air = show/broadcast(방송하다). air a program 연어.
29. length  정답 (b) duration  (보기: distance / duration / weight / height)
문맥 단서 The show's length is two hours(쇼의 ~은 두 시간) → '기간'.
오답 함정 distance/height는 length의 물리적 길이 이미지에서 오는 함정.
지도 팁 length = 길이 / 기간(duration). long(형)과 연결.
30. potential  정답 (a) promise  (보기: promise / danger / price / limit)
문맥 단서 ideas have strong potential to become real products(제품이 될 ~) → '잠재력'.
오답 함정 limit/danger는 반대 방향의 함정.
지도 팁 potential(명) = possibilities/ability/promise(잠재력). potential(형) = possible.
