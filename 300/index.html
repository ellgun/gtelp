핵심요약본

1. 헷갈리기 쉬운 단어 (구별 포인트)

  • lose vs miss — lose는 잃다·지다(lose interest), miss는 놓치다·그리워하다(miss a chance).
  • cost vs spend — cost는 비용이 들다(사물이 주어), spend는 돈·시간을 쓰다(사람이 주어).
  • late vs lately — late는 늦게, lately는 최근에.
  • lead vs led — lead(이끌다)의 과거형은 led.
  • remember vs remind — remember는 기억하다, remind A to B는 A에게 B를 상기시키다.
  • close (닫다 / 가까운) — 발음은 같은 [klouz], 뜻은 동사(닫다)·형용사(가까운)로 나뉨.
  • park vs garden — park는 공원(공공), garden은 정원(개인 뜰).
  • resource vs source — resource는 자원, source는 원천·출처.
  • personal vs personnel — personal은 개인의, personnel은 직원들(인사).
  • economic vs economical — economic은 경제의, economical은 절약하는.
  • capable vs able — capable of ~ing(~할 능력이 있는), be able to + 동사원형(~할 수 있다).
  • affect vs effect — affect는 동사(영향을 주다), effect는 명사(효과).
  • complete vs compete — complete는 완료하다, compete는 경쟁하다·참가하다.
  • favorite vs favor — favorite은 좋아하는, favor는 호의·부탁.

2. 다의어 (뜻이 여러 개인 단어)

  • play — 경기하다 / 연주하다 / 연극
  • article — 기사 / 물품(article of clothing)
  • take — 받다 / 타다 / 데려가다 (take A to B)
  • present — 발표하다 / 현재의 / 선물
  • record — 기록 / 기록하다 / 음반
  • order — 순서 / 주문하다
  • state — 상태 / 주(州) / 말하다 (※ 필수 300보다 DAY01 교재 참고)
  • light — 빛 / 가벼운
  • object — 물체 / 목적 / 반대하다
  • bill — 고지서 / 법안
  • charge — 요금 / 청구하다 / 책임
  • return — 돌아오다 / 돌려주다 / 수익
  • board — 이사회 / 탑승하다 / 판자
  • form — 형태 / 형성하다 / 서식
  • leave — 떠나다 / 남기다 / 휴가 (leave home, 휴가)
  • fail — 실패하다 / 시험에 떨어지다 (fail a test)

3. 시험 빈출 동의어 묶음

  • finish · complete → 끝내다 / complete(형: 완전한)
  • increase · rise → 늘다 / reduce(반의어)
  • vacation · holiday → 휴가 / ordinary · common · usual → 보통의
  • approach · reach · arrive at → 도달하다 / reject · refuse → 거절하다
  • expense · cost → 비용 / fee · charge → 요금
  • start · begin → 시작하다 / keep · maintain → 유지하다
  • difficult · hard → 어려운 / easy · simple → 쉬운
  • choose · select → 선택하다 / pay · spend → 돈을 쓰다
  • research · study · learn → 공부/연구하다 / describe · portray → 묘사하다
  • lead · guide → 이끌다 / exhibit · display → 전시하다
  • huge · enormous · giant → 거대한 / danger · risk → 위험
  • alive · living → 살아 있는 / dead · death(죽음)
  • outside · abroad · overseas · foreign → 외국(의) 계열
  • wealthy · rich → 부유한 / poor → 가난한 (반의어)
  • clear · obvious · plain → 분명한 / clean · pure → 깨끗한

4. 품사·파생어 체크

  • decide → decision(명) / prevent → prevention(명)
  • announce → announcement(명) / describe → description(명)
  • customer(고객) · personal(개인의) → personality(성격)
  • effective(효과적인) → efficient(효율적인): 혼동 주의
  • produce(동) → product(명 제품) → production(명 생산)
  • popular → popularity(명) / economy(명) → economic(형)
  • satisfied(형 만족한) ↔ satisfying(형 만족을 주는)
  • interest(명 흥미) ↔ interesting(형 흥미로운) ↔ interested(형 흥미를 느끼는)
