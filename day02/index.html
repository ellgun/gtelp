2. 헷갈리기 쉬운 단어 (구별 포인트)

  • assess vs access — assess는 평가하다(assessment), access는 접근(하다)·이용(하다).
  • emerge vs emergency — emerge는 나타나다(emergence: 출현), emergency는 비상(사태).
  • expense vs expensive — expense는 돈·경비(명사), expensive는 비싼(형용사). cover expenses = 비용을 치르다.
  • glad vs gladly — glad는 기쁜(형용사), gladly는 기꺼이(부사).
  • conscious vs unconscious — conscious는 의식하고 있는, unconscious는 의식이 없는·무의식적인.
  • considerable vs considerate vs considerably — 상당한 / 사려 깊은 / 상당히(부사).
  • personality vs personal vs individual — personality는 성격, personal은 개인적인, individual은 개인(의)·개별적인.
  • appear vs appearance — appear는 나타나다·~처럼 보이다(동사), appearance는 외모·출연(명사).
  • export vs import — export는 수출(하다), import는 수입(하다).
  • justice vs injustice — justice는 공정·정의, injustice는 불공평·부당함.
  • currency vs current — currency는 통화·화폐, current는 현재의(철자 혼동 주의).
  • principle vs principal — principle은 원칙·원리, principal은 주된·교장(참고, 교재 외).
  • contemporary vs temporary — contemporary는 현대의·동시대의, temporary는 임시의(참고, 교재 외).
  • estimate 발음 — 명사 [éstəmət], 동사 [éstəmèit] (발음 구별).

4. 품사 & 파생어 체크

  • apparent → apparently(부) / define → definition(명) / essential → essence(명), essentially(부)
  • consequence → consequently(부) / assess → assessment(명) / individual → individually(부)
  • situation → situate(동) / achieve → achievement(명) / conclusion → conclude(동)
  • considerable → considerate(형), considerably(부) / concentrate → concentration(명)
  • domestic → domestically(부) / appearance → appear(동) / estimate → estimation(명)
  • publicize → publicity(명) / generate → generation(명) / alternative → alternatively(부)
  • deny → denial(명) / justice → injustice(명) / demonstrate → demonstration(명)
  • confirm → confirmation(명) / divided → divide(동) / conscious → consciousness(명), unconscious(형)
  • emphasis → emphasize(동) / emerge → emergence(명) / establish → establishment(명) / desire → desirable(형)

학습 팁

  • 뜻만 외우지 말고 동의어 묶음으로 함께 외우기 (예: essential · vital · crucial · critical · key · integral).
  • 헷갈리는 쌍(assess/access, emerge/emergency, considerable/considerate)은 예문 한 개씩으로 구별하기.
  • 다의어는 품사와 예문을 같이 적어 두기 (run, cover, face, hold, capacity, establish).
  • 지텔프 동의어 출제 유형(Part 5)은 문장 속 뜻을 먼저 파악한 뒤 보기를 고르기 — run a café = manage, cover expenses = pay.
