  • settle · solve · resolve → 해결하다 / settle · pay · clear → (빚을) 청산하다
  • fundamental · essential · primary · basic → 근본적인 / literature · paper · thesis · dissertation → 논문, 문헌
  • air · show · broadcast · televise → 방송하다 / favor · prefer → 선호하다 / favor · kindness · politeness → 호의
  • largely · mostly · mainly → 대부분 / main · major · leading · chief → 주된
  • direction · course · path → 방향 / direction · control · supervision · oversight → 지휘, 감독
  • manufacturer · producer · maker → 제조회사 / factor · element · component → 요인
  • decline · fall · drop · decrease · diminish · worsen → 하락하다 / decline · refuse · reject → 거절하다
  • location · place · point → 위치 / wage · pay · payment · income · salary → 임금
  • limit · confine · curb · restrict · restrain · control → 제한하다
  • potential · possible · likely · hidden → 잠재적인 / damage · harm · destruction → 손상
  • obvious · clear · apparent · evident → 명백한 / legislation · law · regulation → 법률
  • length · duration · period → 기간 / practical · actual · realistic → 현실적인
  • relatively · comparatively · somewhat → 비교적 / an array of · a range of → 다양한
  • regarding · about · concerning · as to → ~에 관한
  • release · free · liberate · discharge → 풀어주다 / release · publish · issue → 공개하다 / release · launch · unveil → 발매하다
  • sequence · order → 순서 / sequence · series · succession → 연속
  • assign · give · allocate · delegate → 맡기다 / assign · appoint · elect → 임명하다

  • phase · stage · state · step → 단계

2. 헷갈리기 쉬운 단어 (구별 포인트)

  • impact vs effect — 둘 다 '영향'. effect는 효과, 영향(명사)이고 effective(효과적인)로 파생. (affect는 동사 '영향을 미치다', 참고 교재 외)
  • main vs leading — 둘 다 '주된'. main은 주된, leading은 앞장서는, 선도적인.
  • limit vs edge — 둘 다 '가장자리, 한계'의 뜻이 있지만, edge는 지텔프에서 '우위(advantage)'로 자주 출제.
  • able vs unable — ~할 수 있는 / ~할 수 없는. ability는 능력(명사).
  • accept vs except — 수락하다 / ~을 제외하고(참고, 교재 외).
  • large vs largely — 큰(형) / 대부분(부).
  • direct vs direction — direct는 직접적인(형)·지휘하다(동), direction은 방향·지휘(명).
  • long vs length — 긴(형) / 길이·기간(명).
  • practical vs practicality — 현실적인(형) / 실용성(명).
  • necessary vs necessarily — 필요한(형) / 반드시(부). not necessarily = 반드시 ~인 것은 아닌.
  • origin vs original — 기원(명) / 원래의, 독창적인(형).
  • threat vs threaten — 위협(명) / 위협하다(동).
  • diet vs dietary — 식단(명) / 식이의(형).
  • depart vs departure — 출발하다(동) / 출발, 일탈(명).
  • various vs vary vs variety — 다양한(형) / 다양하다(동) / 다양성(명).

3. 다의어 (뜻이 여러 개인 단어)

  • settle — 해결하다 / (빚을) 청산하다 / 정착하다
  • air — 방송하다(동) / 공기(명) / 항공(명)
  • favor — 호의·친절(명) / 선호하다(동)
  • direction — 방향 / 지휘·감독
  • decline — 하락·감소(명) / 하락하다(동) / 거절하다(동)
  • limit — 제한·한도(명) / 제한하다(동)
  • potential — 잠재적인(형) / 잠재력(명)
  • release — 풀어주다 / 공개하다·발표하다 / 발매하다
  • sequence — 순서 / 연속 · measure — 조치 / 기준 / 측정하다
  • assign — 맡기다·할당하다 / 임명하다 · permanent — 영구적인 / 상근직의
  • edge — 가장자리 / 우위 · vary — 다양하다 / 다르게 하다
  • departure — 출발 / 일탈 · sort — 종류(명) / 분류하다(동)

4. 품사 & 파생어 체크

  • settle → settlement(명) / favor → favorite(명·형) / effect → effective(형)
  • large → largely(부) / direction → direct(형·동) / manufacturer → manufacture(동)
  • leading → lead(동) / limit → limited(형), limitation(명) / potential → potentially(부)
  • damage → damaged(형) / obvious → obviously(부) / length → long(형)
  • practical → practicality(명) / relatively → relative(형) / not necessarily → necessary(형), necessarily(부)
  • scientific → science(명) / assign → assignment(명) / able → unable(형)
  • origin → original(형) / pollution → pollute(동) / accept → acceptance(명)
  • occasional → occasionally(부) / vary → various(형) / threat → threaten(동)
  • diet → dietary(형) / departure → depart(동) / authorize → authorization(명)

학습 팁

  • 동사 동의어(settle·solve·resolve, limit·restrict·confine, assign·appoint)는 묶음으로 함께 외우기.
  • 한 단어에 여러 뜻이 있는 단어(settle, decline, release, edge, assign, limit)는 문장 속 뜻을 같이 적어 두기.
  • 지텔프 동의어 출제 유형은 문맥으로 판단 — settle a dispute = solve, favors tea = prefers, declined = worsened.
  • 파생어 쌍(effect/effective, length/long, origin/original)은 품사 구별이 핵심.
  • 틀린 문제는 다음 날 Part 4와 Part 1부터 다시 풀어보기.
