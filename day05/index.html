2. 헷갈리기 쉬운 단어 (구별 포인트)

  • complimentary vs complementary — 무료의·칭찬하는 / 보완하는(참고, 교재 외).
  • experience vs undergo — 둘 다 '겪다'. undergo는 수술·변화 등을 겪을 때 자주 쓰임.
  • raise vs arise vs rise — raise(타동사: 들어 올리다, 언급하다) / arise(자동사: 발생하다) / rise(자동사: 오르다).
  • raise 의 뜻 — 지텔프에서는 raise an issue = mention(언급하다)이 자주 출제.
  • recognize vs identify — 알아보다는 identify, (가치를) 인정하다는 accept. 지텔프: recognized = accepted.
  • determine vs decide — 알아내다 = identify(지텔프), 결정하다 = decide.
  • alter vs change — 거의 같은 뜻의 동사 묶음(modify, vary).
  • attach vs attribute — attach = 붙이다·첨부하다 / attribute = 자질(명)·돌리다(동).
  • require vs requirement — 필요하다(동) / 요건(명).
  • scarce vs scarcely — 부족한(형) / 거의 ~않다(부).
  • responsible vs responsibility — 책임지고 있는(형) / 책임(명).
  • religion vs religious — 종교(명) / 종교의, 독실한(형).
  • candidate vs candid — 후보 / 솔직한(참고, 교재 외).
  • property vs proper — 재산 / 적절한(철자 혼동 주의, 참고).

학습 팁

  • 동사 동의어(alter·change·modify, attach·join·fasten, abandon·dump·discard)는 묶음으로 함께 외우기.
  • 한 단어에 여러 뜻이 있는 단어(raise, commit, recognize, reflect, determine)는 문장 속 뜻을 같이 적어 두기.
  • 지텔프 동의어 출제 유형 — committed = dedicated, recognized = accepted, reflects = reveals, exceeded = surpassed, raised = mentioned, determine = identify, attribute = trait.
  • 파생어 쌍(response/respond, requirement/require, scarce/scarcely)은 품사 구별이 핵심.
  • 틀린 문제는 다음 날 Part 4와 Part 1부터 다시 풀어보기.
