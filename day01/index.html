2. 헷갈리기 쉬운 단어 (구별 포인트)

  • ensure vs assure — ensure는 결과·상황을 보장(ensure satisfactory results), assure는 사람에게 장담(assure A that ~).
  • affect vs effect — affect는 동사(영향을 주다), effect는 명사(효과).
  • adopt vs adapt — adopt는 채택하다/입양하다, adapt는 적응하다.
  • economic vs economical — economic은 경제의, economical은 절약하는(경제적인).
  • income vs revenue — income은 개인·기업의 수입, revenue는 기업의 매출(총수입).
  • resource vs source — resource는 자원, source는 원천·출처.
  • theory vs hypothesis — theory는 검증된 이론, hypothesis는 아직 검증 전인 가설.
  • capable vs able — capable of + ~ing(능력), be able to + 동사원형(할 수 있다).
  • acquire vs require — acquire는 획득하다·인수하다, require는 요구하다.
  • state vs declare — state는 말하다(진술), declare는 공식적으로 선언하다.
  • seek vs search — seek는 추구하다·구하다(추상적/목표), search는 뒤지다·수색하다.
  • circumstance vs circumstances — 복수형 circumstances로 자주 쓰임 (under the circumstances: 이런 상황에서).

3. 다의어 (뜻이 여러 개인 단어)

  • work — 일하다(work as a nurse) / 작품(works of Leonardo da Vinci) / 작동하다(work = function)
  • state — 말하다 / 상태(state of shock) / 주(state of California)
  • part — 부분, 일부(a key part) / 부품(auto parts)
  • address — (문제를) 다루다·해결하다 / 주소 / 연설
  • benefit — 이점, 이득 / 이득을 주다 (benefit from ~ : ~로부터 이익을 얻다)
  • secure — 안전한(a secure place) / 확보하다·따내다(secure a contract)
  • function — 기능 / 작동하다 (perform functions : 기능을 수행하다)
  • surface — 표면 / (face와 유사) 겉면
  • appointment — 임명 / 약속 (과 다의어) · professional — 전문적인 / 전문가
  • range — 범위 / 다양함 (a range of ~ : 다양한 ~)
  • scheme — 계획 / 책략·음모
  • aim — 목표 / 목표로 하다 (aim to + 동사원형)

4. 품사 & 파생어 체크

  • aware → awareness(명) / initial → initially(부) / legal → illegal(반의)
  • maintain → maintenance(명) / remove → removal(명) / assure → assurance(명)
  • knowledge → knowledgeable(형) / function → functional(형) / region → regional(형)
  • previous → previously(부) / indicate → indication(명) / appropriate → appropriately(부), inappropriate(반의)
  • specific → specifically(부) / economic → economy(명) / professional → profession(명), professionally(부)
  • investigate → investigation(명), investigator(명) / acquire → acquisition(명) / declare → declaration(명)
  • additional → add(동), addition(명) / conflict → conflicting(형)
